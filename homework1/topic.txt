Команда создания топика:

```bash
bin/kafka-topics --create --topic my-topic --bootstrap-server kafka-0:29092 --partitions 3 --replication-factor 2
```

Команда describe внутри контейнера:

```bash
bin/kafka-topics --describe --topic my-topic --bootstrap-server kafka-0:29092
```
